# Правило данных апертур и рекомендаций Vega-SMD

Базовый нормативный источник общих правил — IPC-7525C (November 2021), в том числе разделы 3.2.1, 3.2.1.2, 3.2.3.5 и Figure 3-10 для chip-компонентов. Это руководство, поэтому подтверждённые данные производителя конкретного компонента имеют приоритет.

Справочный источник для C0402 (EIA 0402 / 1005 Metric): Worthington Assembly, “Discrete Component Footprint Recommendations”, Rev E. Для footprint 0402 в документе указаны: площадка 0,60 × 0,40 мм, зазор между площадками 0,70 мм, шаг 1,00 мм. Это рекомендация сборочного производства, а не datasheet производителя компонента; в окне она должна иметь источник «Worthington Assembly», а не «производитель компонента».

Найденные производственные источники не смешивать между корпусами: Murata для собственного Silicon Capacitor 0402 указывает апертуру 0,369 × 0,260 мм при толщине 0,125 мм, а для 0402M — 0,260 × 0,240 мм при толщине 0,100 мм. Для MLCC C0402 эти значения недействительны без отдельного подтверждения. Indium допускает для дискретных компонентов технологическое уменьшение 10–20%; AIM связывает минимальный размер апертуры с типом порошка. Такие сведения относятся к технологической рекомендации, а не к геометрии конкретного MLCC.

Все числовые размеры апертур, посадочных площадок, межцентровых расстояний и занятой области берутся только из документации производителя. Размеры нельзя получать из изображения приблизительно, вычислять по масштабу или заменять типовыми значениями.

После отображения исходных размеров отдельным разделом пишутся рекомендации Vega-SMD:

- изменение размера апертуры;
- изменение формы апертуры;
- рекомендуемая толщина трафарета.

В окне выводятся два независимых блока: «Рекомендация производителя» и «Расчётная рекомендация Vega-SMD». Для производителя показывается только подтверждённое значение или диапазон; при отсутствии данных указывается «не указано производителем». Расчётная толщина по Area Ratio и Aspect Ratio выводится диапазоном `0 < t ≤ min(t_AR, t_area)` либо от подтверждённой технологической нижней границы, если она есть. Этот диапазон никогда не выдаётся как факт или рекомендация производителя.

Уменьшение апертуры показывается прежде всего абсолютным значением на каждую сторону в мм. Процент является дополнительным пересчётом относительно размера соответствующей площадки; при исходном процентном источнике сохраняются оба представления.
