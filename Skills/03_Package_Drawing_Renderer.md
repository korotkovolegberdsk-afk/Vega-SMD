# Package Drawing Renderer

## Scope

Применять при рендеринге Top, Side, End и 3D-представлений корпуса в инженерном режиме.

## Mandatory Rules

- Рисовать только verified manufacturer geometry.
- Использовать единый `ScalePxPerMm` для ортографических проекций одного Package.
- Сохранять реальные пропорции X:Y:Z в 3D-представлении.
- Показывать только существующие в источнике проекции и размерные данные.
- Показывать Pin 1 только там, где он подтверждён источником.
- При отсутствии проекции выводить явное сообщение.

## Forbidden

- Использовать generic, parametric или family-based fallback в engineering drawing.
- Строить выводы по LeadCount или Pitch без verified coordinates.
- Рисовать нулевые, неподтверждённые или выведенные размеры.
- Искажать геометрию независимо по осям ради заполнения области.
- Подменять корпус land pattern или footprint.

## Workflow

1. Загрузить текущий verified geometry dataset и его проекции.
2. Проверить единицы координат и источник.
3. Рассчитать общий масштаб без изменения исходных координат.
4. Применить только scale и translation для размещения.
5. Нарисовать подтверждённые primitives, размеры и Pin 1.
6. Для отсутствующих данных показать диагностическое сообщение.

## Verification

- Top, Side и End используют один масштаб mm-to-pixel.
- Количество и форма выводов соответствуют verified primitives.
- Отсутствующая проекция не заменяется шаблонной.
- Footprint-данные не участвуют в mechanical drawing.
