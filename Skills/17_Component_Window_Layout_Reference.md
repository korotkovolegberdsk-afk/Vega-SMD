# Эталон компоновки окон компонента

Файл `blank-window-layout.svg` является эталоном расположения окон полной карточки Vega-SMD.

Компоновка состоит из:

- левого блока «Чертёж корпуса» с четырьмя пустыми подокнами 2×2;
- правого верхнего окна «Апертуры трафарета»;
- правого нижнего окна «Лента»;
- общего верхнего заголовка.

При дальнейшей работе изменяется только содержимое соответствующего окна. Рамки, пропорции и расположение остальных окон не изменяются без отдельного запроса.
