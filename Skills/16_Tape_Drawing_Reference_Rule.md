# Правило отображения ленты Vega-SMD

Присланный пользователем образец рисунка ленты является эталоном композиции, ориентации SOT23, цвета и стиля линий.

Допускаются только явно запрошенные изменения:

- удаление указанных лишних размеров;
- перевод указанных надписей на русский язык.

Катушку, дополнительные размеры, легенды, рекомендации и другие элементы нельзя добавлять без прямого запроса пользователя. Геометрия ленты и ориентация компонента должны соответствовать образцу и подтверждённым данным производителя.
