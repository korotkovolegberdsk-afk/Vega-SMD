# Vega-SMD Codex Workflow

> Утверждённая карточка от 06.09.2026: перед работой полностью прочитать `D:/Projects/Vega-SMD/Skills/26_Approved_Component_Card_Rule.md` и просмотреть указанный там PNG. При конфликте оформления применять правило 26: пять карманов C0402, исходные апертуры 0,60 × 0,40, уменьшение только в тексте, единая тёмная палитра и шрифты. Старые указания ниже не должны возвращать отменённый вид. Источники данных других компонентов проверять отдельно.

Перед любыми изменениями проекта:

1. Прочитать:
   Vega-SMD_RULES.md

2. Определить относящиеся к задаче Skills.
   Для задач карточек компонентов и engineering drawing обязательно читать `Skills/10_Vega_SMD_Component_Card_Reference.md`.

3. Прочитать соответствующие файлы из:
   /Skills

4. До изменения файлов проверить:
   - не нарушается ли архитектура Master Library;
   - не используется ли generic geometry вместо verified manufacturer data;
   - не затрагиваются ли БД/модели/сервисы без необходимости;
   - есть ли актуальная migration, если меняется БД.

5. После изменений:
   - собрать затронутые проекты;
   - запустить targeted tests;
   - показать список изменённых файлов;
   - проверить результат против Vega-SMD_RULES.md;
   - явно указать, какие Skills были применены.

6. Если данных недостаточно:
   не придумывать значения;
   остановиться и сообщить, каких verified данных не хватает.
