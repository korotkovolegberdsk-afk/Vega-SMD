# SOD723 display geometry

Source: https://www.nxp.com/docs/en/package-information/SOD723.pdf (2016-02-08).
The shared top, bottom, side, 3D and tape mesh is a documented parametric model.

Nominal display values in mm: overall length 1.40; body 1.00 x 0.60;
height 0.52; lead width 0.285 (displayed 0.29); lead thickness 0.115
(displayed 0.12); flat lead length 0.20.

The reflow footprint is represented by pads 0.50 x 0.42 at 1.00 centre spacing.
The reference tape illustration uses W=8 and P=2; its cavity values are Estimated.
