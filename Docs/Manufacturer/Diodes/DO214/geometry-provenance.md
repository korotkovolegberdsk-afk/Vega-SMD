# SMA, SMB and SMC display geometry

Sources: Diodes Incorporated package sheets SMA (2017-03-14), SMB
(2019-08-30) and SMC (2017-03-14). The program uses one documented
parametric mesh per unique package for all views and the tape illustration.

Displayed nominal values are midpoints of the source limits:

| Package | Overall | Body | Body width | Lead width | Height | Lead thickness | Foot |
|---|---:|---:|---:|---:|---:|---:|---:|
| SMA | 5.20 | 4.30 | 2.61 | 1.45 | 2.18 | 0.23 | 1.14 |
| SMB | 5.30 | 4.32 | 3.62 | 2.09 | 2.25 | 0.23 | 1.14 |
| SMC | 7.94 | 6.86 | 5.91 | 2.97 | 2.25 | 0.23 | 1.14 |

Suggested pads (X x Y, centre spacing): SMA 2.50 x 1.70, 4.00;
SMB 2.50 x 2.30, 4.30; SMC 2.50 x 3.30, 6.90.

Tape: SMA W=12 and P=4; SMB W=12 and P=8; SMC W=16 and P=8.
P0=4 and hole diameter=1.5. A0/B0/K0 are source-defined by component
size, so illustration cavity dimensions are stored as Estimated.
