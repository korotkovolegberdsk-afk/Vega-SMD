# SOD523 display geometry

Source: https://www.diodes.com/assets/Package-Files/SOD523.pdf (2016-04-11).
The shared top, bottom, side, 3D and tape mesh is a documented parametric model.

Nominal display values in mm (midpoints where the source gives limits only):
overall length 1.60; body 1.20 x 0.80; height 0.60; lead width 0.30;
lead thickness 0.14; flat lead length 0.20.

Suggested pads: X=0.60, Y=0.70, outer span X1=2.00; centre spacing=1.40.
Tape is shown at W=8, P=4, P0=4 and hole diameter 1.5. Cavity values are
reference illustration data and are marked Estimated, not manufacturer-verified.
