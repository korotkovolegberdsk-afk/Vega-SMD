# SOD923 display geometry

Source: https://www.diodes.com/assets/Package-Files/SOD923-0.2mm-Lead-Width.pdf
(2015-06-05). Only the 0.2 mm lead-width package is used; the 0.3 mm variant is
not added as a duplicate package type.

Nominal values in mm: overall length 1.00; body 0.80 x 0.60; height 0.37;
lead width 0.20; lead thickness 0.12; flat lead length 0.10.
Suggested pads are 0.30 x 0.40 at C=0.90. The reference tape illustration
uses W=8 and P=2; its cavity values are Estimated.
